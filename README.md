# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

**ClassSync – Full-Stack Timetable Management System**

ClassSync is a full-stack web application designed to simplify academic timetable management for colleges and educational institutions. It provides a centralized platform for managing academic schedules, including departments, courses, subjects, faculty members, classrooms, semesters, and time slots.

The application features an interactive frontend that allows users to navigate academic semesters and view organized class schedules. Its backend, built with Node.js and Express.js, provides API endpoints for handling application requests, while MongoDB stores and manages academic and timetable-related data.

**Key Features**
- Interactive timetable viewing for different academic semesters.
- REST API integration between the frontend and backend.
- Backend services for managing academic and timetable data.
- MongoDB database integration for persistent data storage.
- User login functionality.
- Responsive user interface built with React and Tailwind CSS.

**Technology Stack:** React.js, JavaScript, Tailwind CSS, Node.js, Express.js, MongoDB, and Mongoose.

**Objective:** To build a scalable and maintainable timetable management platform that streamlines academic scheduling and provides a foundation for future enhancements such as automated timetable generation and role-based access control.
